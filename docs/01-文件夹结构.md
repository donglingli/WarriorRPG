# 01 - 文件夹结构（按功能分类）

> 返回索引：[项目说明.md](./项目说明.md)

## 1. 源代码结构（`Source/Warrior/`）

| 功能分类 | 目录 / 文件 | 说明 |
| :--- | :--- | :--- |
| **角色** | [`Characters/`](../Source/Warrior/Public/Characters/) | 角色 C++ 基类与英雄/敌人子类 |
| **组件** | [`Components/Combat/`](../Source/Warrior/Public/Components/Combat/) | 战斗组件（武器注册/携带管理） |
| | [`Components/Input/`](../Source/Warrior/Public/Components/Input/) | 自定义增强输入组件 |
| | [`Components/`](../Source/Warrior/Public/Components/PawnExtensionComponentBase.h) | 组件基类（Pawn/Controller 获取工具） |
| **技能系统** | [`AbilitySystem/`](../Source/Warrior/Public/AbilitySystem/) | 自定义 ASC 与属性集 |
| | [`AbilitySystem/Abilities/`](../Source/Warrior/Public/AbilitySystem/Abilities/) | GameplayAbility 基类与英雄/敌人子类 |
| | [`AbilitySystem/GEExecCalc/`](../Source/Warrior/Public/AbilitySystem/GEExecCalc/) | 伤害计算（Execution Calculation） |
| **接口** | [`Interfaces/`](../Source/Warrior/Public/Interfaces/) | 战斗接口（PawnCombatInterface） |
| **数据资产** | [`DataAssets/Input/`](../Source/Warrior/Public/DataAssets/Input/) | 输入配置（Native/Ability 输入映射） |
| | [`DataAssets/StartUpData/`](../Source/Warrior/Public/DataAssets/StartUpData/) | 启动数据（初始技能/GameplayEffect 授予） |
| **物品/武器** | [`Items/Weapons/`](../Source/Warrior/Public/Items/Weapons/) | 武器基类与英雄/敌人武器 |
| **动画** | [`AnimInstance/`](../Source/Warrior/Public/AnimInstance/) | 动画实例基类/角色动画实例 |
| | [`AnimInstance/Hero/`](../Source/Warrior/Public/AnimInstance/Hero/) | 英雄动画实例与链接动画层 |
| **控制器/模式** | [`Controllers/`](../Source/Warrior/Public/Controllers/) | 玩家控制器 |
| | [`GameModes/`](../Source/Warrior/Public/GameModes/) | 游戏模式 |
| **类型/工具** | [`WarriorTypes/`](../Source/Warrior/Public/WarriorTypes/) | 公共类型：[`WarriorEnumTypes.h`](../Source/Warrior/Public/WarriorTypes/WarriorEnumTypes.h)（枚举）+ [`WarriorStructTypes.h`](../Source/Warrior/Public/WarriorTypes/WarriorStructTypes.h)（结构体） |
| | [`WarriorGameplayTags.h`](../Source/Warrior/Public/WarriorGameplayTags.h) | 原生 GameplayTag 声明 |
| | [`WarriorFunctionLibrary.h`](../Source/Warrior/Public/WarriorFunctionLibrary.h) | 蓝图函数库（Tag 工具） |
| | [`WarriorDebugHelper.h`](../Source/Warrior/Public/WarriorDebugHelper.h) | 屏幕调试打印工具 |

约定：`Public/` 与 `Private/` 下的子目录结构一一对应（模块化组织，方便后续拆分模块）。
