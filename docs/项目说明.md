## 1. 项目总览

Warrior 是一个基于 **UE 5.6 + GAS（GameplayAbilitySystem）** 的第三人称近战动作游戏项目，目前已实现：

- **玩家基础系统**：第三人称相机、增强输入（Enhanced Input）、移动/视角控制
- **GAS 技能框架**：自定义 ASC / AttributeSet / GameplayAbility，含两种激活策略（OnTriggered / OnGiven）
- **近战系统**：武器装卸（Equip/Unequip）、轻/重连击、跳终结技、慢动作、Montage 音效
- **武器管理**：武器以 GameplayTag 注册，技能随武器生命周期授予/移除（SpecHandle 管理）
- **伤害系统**（Day5 新增）：攻击碰撞检测（武器 Overlap 委托）→ GameplayEvent → GE Execution 伤害计算（攻防比 + 连击加成）→ `PostGameplayEffectExecute` 扣血 → 死亡 Tag → GA_Death
- **受击反馈**（Day5 新增）：HitReact GA + 材质参数、攻击暂停（时间膨胀）、受击音效并发控制、GameplayCue 击中音效
- **动画系统**：Linked Anim Layers（链接动画层），持械/空手动画切换，idle→relax 状态
- **敌人系统地基**：敌人角色基类、异步加载启动数据、GA 生成武器、CurveTable 属性
