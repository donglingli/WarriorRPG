## 5.1 英雄启动流程（同步加载）

1. `AWarriorHeroCharacter::PossessedBy()` 触发
2. 软引用 `CharacterStartUpData` → `LoadSynchronous()` 同步加载
3. `UDataAsset_StartUpDataBase::GiveToAbilitySystemComponent()`：
   - 授予 `ActiavteOnGivenAbilities`（授予即激活，如装备/卸装备技能）
   - 授予 `ReactiveAbilities`（被动/反应技能）
   - 应用 `StartUpGameplayEffects`（属性初始化，来源 CurveTable）
4. 英雄版额外授予 `HeroStartUpAbilitySets`（每个技能带 `InputTag`，写入 `DynamicAbilityTags`）

## 5.2 敌人启动流程（异步加载）

- 与英雄一致，但通过 `UDataAsset_EnemyStartUpData`，使用 `RequestAsyncLoad` 异步加载启动数据

## 5.3 输入 → 技能激活链路

```
Enhanced Input (IA_xxx)
  → UWarriorInputComponent::BindAbilityInputAction（按 InputTag 批量绑定）
    → AWarriorHeroCharacter::Input_AbilityInputPressed(InputTag)
      → UWarriorAbilitySystemComponent::OnAbilityInputPressed(InputTag)
        → 遍历 GetActivatableAbilities()，匹配 DynamicAbilityTags
          → TryActivateAbility(SpecHandle)
```

## 5.4 武器装卸（技能随武器生命周期）

1. 按下装备输入 → 触发 Equip 技能（`OnGiven` 策略）→ 播放装备 Montage
2. AnimNotify 触发 GameplayEvent（`Player_Event_Equip_Axe`）
3. GA 监听事件 → 生成武器 → `UPawnCombatComponent::RegisterSpawnedWeapon(Tag, 武器)` 注册
4. `UWarriorAbilitySystemComponent::GrantHeroWeaponAbilities()` 授予武器技能
5. `SpecHandle` 存入 `AWarriorHeroWeapon`；卸装备时 `RemoveGrantedHeroWeaponAbilities()` 移除
6. 装备同时切换 `WeaponAnimLayerToLink`（链接动画层）与 `WeaponInputMappingContext`

## 5.5 攻击 → 碰撞 → 伤害 → 扣血 → 死亡链路（Day5 新增）

**① 碰撞开关与命中事件**

```
攻击 Montage 中的 AnimNotifyState（ANS_ToggleWeaponCollision，蓝图）
  → UPawnCombatComponent::ToggleWeaponCollision(bEnable, EToggleDamageType)
    → 开启：武器碰撞盒设为 QueryOnly；关闭：NoCollision 并清空 OverlappedActors
武器碰撞盒 BeginOverlap / EndOverlap（AWarriorWeaponBase）
  → OnWeaponHitTarget / OnWeaponPulledFromTarget 委托
    → UPawnCombatComponent::OnHitTargetActor（注册武器时绑定）
      → UHeroCombatComponent 重写：OverlappedActors 去重后发送 GameplayEvent
        - Shared.Event.MeleeHit（攻击 GA 监听 → 计算伤害、应用 GE）
        - Player.Event.HitPause（攻击暂停/时间膨胀）
```

**② 伤害计算（GEExecCalc）**

- 攻击 GA 收到 MeleeHit 事件 → 取目标 ASC → 构造 GE SpecHandle，通过
  `BP_ApplyEffectSpecHandleToTarget()` 应用到目标
- Spec 通过 SetByCaller 携带：`Shared.SetByCaller.BaseDamage`（武器基础伤害，来自
  `GetHeroCurrentEquippedWeaponDamageAtLevel()`）、`Player.SetByCaller.AttackType.Light/Heavy`（连击段数）
- `UGEExecCalc_DamageTaken::Execute()` 捕获 `AttackPower`(Source) / `DefensePower`(Target) / `DamageTaken`(Target)：
  - 轻攻击连击加成：每多 1 段 +5%；重攻击连击加成：每多 1 段 +10%
  - **最终伤害 = 基础伤害 × AttackPower / DefensePower**，以 Override 写入 `DamageTaken`

**③ 扣血与死亡**

```
PostGameplayEffectExecute（UWarriorAttributeSet）
  → DamageTaken 扣减 CurrentHealth（钳制 [0, MaxHealth]）
    → 血量归零 → AddGameplayTagToActorIfNone(Shared.Status.Death)
      → GA_Death（蓝图，监听 Death Tag）处理消融/粒子/销毁（逻辑与表现解耦）
```

> 音效分类： AnimNotify 触发的音效走 AnimNotify + 并发控制；击中音效走 GameplayCue。
