# Docs

项目的**学习与设计文档**。规则见 [`Guide/README.md`](Guide/README.md)。

| 路径 | 内容 |
|---|---|
| [`Guide/`](Guide/) | 记录规则：写什么、什么时候写、什么算合格 |
| [`Journal/`](Journal/) | 每日笔记，`YYYY-MM-DD.md` |
| [`DesignDecisions.md`](DesignDecisions.md) | 设计判断台账：每个设计决定的取舍与理由 |
| [`Bugs/`](Bugs/) | 踩坑记录：现象 → 误判 → 根因 → 复现 |
| [`Experiments/`](Experiments/) | 实验结论与数据（bench、布局打印、编译耗时） |

---

**这里的文档和代码一起进版本库**，是项目的一部分，不是临时笔记。

计划类文档（学习大纲、任务卡）不在这里，它们会频繁变动，放在项目之外。
